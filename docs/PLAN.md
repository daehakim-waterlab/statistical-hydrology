# Plan of the book

Statistical Hydrology is an undergraduate textbook in four parts. It starts from probability, builds up the distributions and estimation methods used for hydrological design, and ends with inference, time series and dependence. Every chapter follows the same pattern: core ideas, theory with derivations, worked examples computed in Python, a planned lab where relevant, common mistakes, problems with answers, and further reading.

## Writing rules

- American English; SI units.
- Chapter examples use invented numbers or synthetic data generated by the code. Real records appear only in the labs, with their source and license.
- All text, derivations, figures, tables, examples and problems are original. Standard definitions and formulas are written in our own notation and words; reference books appear only under "Further reading".
- Statistical tables are computed with SciPy, not copied.
- Python (NumPy, SciPy, Matplotlib) only, so every result can be reproduced in Colab.

## Relation to the other books
