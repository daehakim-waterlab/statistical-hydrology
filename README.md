# Statistical Hydrology

An undergraduate online textbook for the Statistical Hydrology course, Department of Civil Engineering, Jeonbuk National University.

**Read it at <https://hydroclimatol.com/statistical-hydrology/>** · [PDF](https://hydroclimatol.com/statistical-hydrology/statistical-hydrology.pdf)

Built with [Jupyter Book](https://jupyterbook.org/) 1.x, with the same setup as the [Engineering Hydrology](https://github.com/daehakim-waterlab/engineering-hydrology) and [Physical Hydrology](https://github.com/daehakim-waterlab/physical-hydrology) books. The plan of the book is in [`docs/PLAN.md`](docs/PLAN.md).

## Layout

- `_config.yml`: book settings (MathJax, code execution, PDF, footer "© Daeha Kim" and license, header link to the lab homepage).
- `_toc.yml`: four parts, fifteen chapters and two appendices. Chapter, section, figure, table and equation numbers are written by hand in the chapter files.
- `intro.md`: the front page.
- `chapters/chNN_*.md`, `appendices/appX_*.md`: one MyST Markdown notebook per chapter. Python code goes in `{code-cell} python` blocks and runs on every build. Tag a cell `hide-input` to fold its code under the figure, `remove-input` to show only its output, or `remove-cell` to run it without showing it (plot style; numbers glued into the text with `{glue:text}`).
- `labs/`: Colab notebooks, one per chapter, using real open data (not executed during the book build).
- `_static/custom.css`, `_templates/lab-home.html`: styling for phones and dark mode, and the "Lab homepage" header link.
- `docs/`: planning notes (not part of the book).

## Writing rules

- American English spelling. SI units only; formulas first published in other units are converted, and the converted form is checked against the original in code.
- Worked examples and figures in the chapters use invented numbers or synthetic data generated by the code. Real data appear only in the labs, with their source and license stated.
- All text, derivations, figures, tables, examples and problems are original. Reference books appear only under "Further reading".
- Equations that are referred to are written as `\begin{equation*} ... \tag{n.k} \end{equation*}` and cited as "(n.k)".
- Figure palette: series `#2a78d6`, `#eb6834`, `#1baf7a`; text `#0b0b0b`, secondary `#52514e`; background `#fcfcfb`.

## Build locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter-book build .
open _build/html/index.html
```

The PDF needs XeLaTeX (TeX Live); `jupyter-book build . --builder pdflatex` writes `_build/latex/statistical-hydrology.pdf`. CI builds it for you.

## Publishing

`.github/workflows/deploy.yml` builds the HTML and the PDF on every push to `main` and deploys them to GitHub Pages (Settings → Pages → Source: "GitHub Actions"). A code cell that raises an error, or any build warning, stops the deployment, and the previous version stays online. A failed PDF build does not stop it.
